Yöntem 1: React Native (Expo Go) ile Doğrudan Mobil Uygulama

          
İndirilebilir kose_oku_mobil_paketi.zip içindeki mobile/ klasöründe npx expo start komutunu çalıştırıp telefonunuzdaki Expo Go (iOS / Android) uygulamasıyla QR kodu okutarak veya eas build -p android ile APK üretip kurarak yerel mobil uygulama olarak kullanabilirsiniz.

        

        

          
Yöntem 2: Python FastAPI Arka Plan Servisi (Ücretsiz Bulut)

          
Paketteki backend/ klasörünü Render.com, Railway veya GitHub Actions üzerine ücretsiz yüklediğinizde her 30 dakikada bir Sözcü, Hürriyet, T24, Cumhuriyet, Karar ve Diken köşe yazılarını otomatik çeker.

        

        

          
Yöntem 3: Ana Ekrana Ekle (Anında PWA Kurulumu)

          
Bu HTML uygulamasını telefon tarayıcınızda (Safari / Chrome) açıp Paylaş → Ana Ekrana Ekle seçeneğine dokunarak tam ekran uygulama ikonuyla hemen kullanabilirsiniz.
